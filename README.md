# 生活雷达

个人决策雷达：核查信息、判断与我有没有关系、会怎样影响我、现在要不要行动，并到期复盘。PWA，部署在 GitHub Pages，运行不依赖 Claude。

## 怎么用
- **今日**：需要行动（最多 3 条）→ 最近 7 天值得知道（重要成卡，一般一句话）→ 暂不判断 → 更早记录。
- **投喂**：贴正文或链接，点提交会打开预填好的 GitHub Issue，点 Submit 即可；截图在 GitHub 页面里粘贴到正文。约 1–2 分钟出结果。
- **复盘**：四层打分（事实 / 影响 / 建议 / 值不值得），归因到底错在哪一环；页面下方可修改画像。

## 自动运行
- 每天北京时间 07:21 联网找近 7 天与画像相关的信息（至少 10 条），核查定级后分析，写入 `data/items.json`；07:51、08:37、11:17 补偿，当天已更新就跳过。
- App 提交的 Issue 由 `intake` 工作流处理：投喂（联网核查 + 分析）、建议状态、复盘、画像。只处理仓库主人提交的内容。
- 两段式：核查（Gemini + Google 搜索）与分析（只推理）分开调用；代码兜底校验：只有 A/B 事实能作依据、影响必须四环完整、建议须相关度 3 且影响置信度中以上、禁用确定性用语、待办建议最多 3 条。

## 配置
- Secrets：`GEMINI_API_KEY`（可选变量 `GEMINI_MODEL`）
- Pages：main / root
- 检索方向、每天条数：`data/config.json`

建议仅供参考，理财维度只给观察项，不构成投资建议。
